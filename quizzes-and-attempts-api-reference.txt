QUIZZES (QuizzesController — base route: /api/Quizzes)
================================================================================

--------------------------------------------------------------------------------
1. CREATE QUIZ
--------------------------------------------------------------------------------
Route:     POST /api/Quizzes
Auth:      Instructor

Sample request body (application/json):
{
  "courseId": 42,
  "title": "Midterm quiz",
  "description": "Optional description",
  "availableFrom": "2026-05-01T10:00:00Z",
  "availableUntil": "2026-06-01T23:59:59Z",
  "maximumAttempts": 3,
  "showResultOnClose": true,
  "shuffleQuestions": false,
  "shuffleOptions": true,
  "status": "Draft",
  "publishedDate": null,
  "attemptTimeLimit": 45
}

Status values: "Draft" | "Published" | "Scheduled"

Validations (CreateQuizCommandValidator + QuizRequestValidator):
  - courseId: required, not null/empty.
  - title: required; not null; max length 200.
  - description: if provided, max length 2000.
  - availableFrom: required; must be >= UTC now (cannot be in the past).
  - availableUntil: required; must be strictly after availableFrom.
  - If status === "Scheduled":
      - publishedDate: required; must be > UTC now; must be < availableFrom.
  - maximumAttempts: > 0 and <= 5.
  - courseId (on quiz): not null.
  - attemptTimeLimit: > 0.

3. UPSERT QUESTIONS (bulk)
--------------------------------------------------------------------------------
Route:     PUT /api/Quizzes/{id}/questions
Auth:      Instructor

Sample request body (application/json):
[
  {
    "id": null,
    "questionText": "What is 2+2?",
    "questionType": "MCQ",
    "mark": 5,
    "instructions": null,
    "explanation": null,
    "options": [
      { "optionId": null, "optionText": "3", "isCorrect": false },
      { "optionId": null, "optionText": "4", "isCorrect": true },
      { "optionId": null, "optionText": "5", "isCorrect": false }
    ]
  }
]

questionType: "MCQ" | "TrueFalse" | "Written"

Validations (UpsertQuestionsCommandValidator):
  - quizId (path): not empty.
  - questions: non-empty list.
  Per question:
  - questionText: required; max 2000.
  - mark: required; > 0 and <= 100.
  - questionType: required; valid enum.
  - instructions: if provided, max 1000.
  - explanation: if provided, max 1000.
  - If questionType is TrueFalse or MCQ:
      - options: required; exactly one option must have isCorrect === true.
      - Each option: optionText required; max 300.
  - If MCQ: options count between 3 and 5 (inclusive).
  - If TrueFalse: exactly 2 options; one option text must be "True" (case-insensitive);
    one must be "False" (case-insensitive).

7. GENERATE QUESTIONS BY AI
--------------------------------------------------------------------------------
Route:     POST /api/Quizzes/{quizId}/generate-by-ai
Auth:      Instructor
Content:  multipart/form-data (FromForm)

Typical parts (names may follow ASP.NET Core model binding conventions):
  - FileIds: optional list of Guid material file IDs (or empty).
  - NewUploadedFiles: optional file uploads.
  - QuestionsCount: int
  - QuestionTypeCounts: dictionary — keys MCQ, TrueFalse, Written with counts
  - QuestionDifficultyPercents: optional — Easy, Medium, Hard as floats summing to 100
  - Query: optional string

Example (conceptual; adjust binding for your HTTP client):
  QuestionsCount: 10
  QuestionTypeCounts[MCQ]: 5
  QuestionTypeCounts[TrueFalse]: 3
  QuestionTypeCounts[Written]: 2
  (or send JSON string for complex types if your client requires)

Validations (GenerateQuestionsCommandValidator):
  - questionsCount: > 0.
  - If FileIds is null or empty: NewUploadedFiles must be non-empty (at least one file).
  - questionTypeCounts: not null; not empty; keys must be only MCQ, TrueFalse, or Written.
  - If questionDifficultyPercents is provided:
      - keys must be only Easy, Medium, Hard.
      - values must sum to 100 (within 0.01 tolerance).

Note: Handler expects FileIds to be usable; prefer sending an empty array [] instead of omitting if no IDs.

3. SAVE ATTEMPT (AUTOSAVE ANSWERS)
--------------------------------------------------------------------------------
Route:     POST /api/Attempts/{attemptId}/save
Auth:      Student
Content:   application/json

Sample request body:
[
  {
    "questionId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "writtenAnswer": null,
    "optionId": "8fa85f64-5717-4562-b3fc-2c963f66afa6"
  },
  {
    "questionId": "4fa85f64-5717-4562-b3fc-2c963f66afa6",
    "writtenAnswer": "Short essay text here.",
    "optionId": null
  }
]

Rules per answer:
  - For MCQ/TrueFalse: use optionId (writtenAnswer optional/empty).
  - For Written: use writtenAnswer (optionId null).

Validations (SaveAttemptCommandValidator):
  - attemptId (path): not empty.
  - answers: at least one item.
  Per answer:
  - questionId: required.
  - writtenAnswer: if provided, max length 2000.
  - If optionId is not provided:
      - writtenAnswer must be non-null and non-empty.
  - If writtenAnswer is null or empty:
      - optionId must be provided and non-empty.

(Each answer must satisfy either option-based OR written text, not neither.)
